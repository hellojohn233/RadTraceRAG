# 风格基调

这份文件是 RadTraceRAG 的视觉底稿。它不是灵感板，是**可以核查的规范**：
界面上出现的每个颜色、字号、间距，都能在 `src/radtracerag/ui/theme.py` 里找到
同名 token。改样式改 token，不改数值。

界面结构与组件行为见 `doc/ui-design.md`。两份文件分工：这份管「长什么样」，
那份管「怎么排、怎么动」。

![风格视觉板](../assets/style-board.png)

## 基调

> **纸面 · 可核查 · 克制**

参照物是**放射科报告和学术论文**，不是 SaaS 控制台。

理由很直接：「可追溯」这件事在纸面上就是引用制度——答案带脚注号，证据按编号列在
下方，每条写明来源。深色发光的面板、卡片堆叠、等宽字标 ID 是工程界面的语言，
跟「一份可以核查的文档」是两回事。

反参照物（明确不要的）：深色科技风、渐变与玻璃拟态、彩色阴影卡片、图标字体、
满屏圆角胶囊、插画式图标。

## 色彩

一色为主，朱砂为唯一强调。

| token | 值 | 用在哪 |
|---|---|---|
| `text` 墨 | `#16202E` | 正文、结构线、影像切片、按钮底 |
| `accent` 朱砂 | `#C0472B` | 引用编号、命中、唯一强调、主操作 |
| `navy` 藏青 | `#234A6E` | 次级强调，备用，默认不用 |
| `bg` 纸白 | `#FBFAF7` | 页面底 |
| `surface` 浅灰 | `#F1EFE9` | 影像灯箱底、侧边栏块 |
| `surface_2` 白 | `#FFFFFF` | 输入框、证据区 |
| `border` 分隔线 | `#E2E0DA` | 分区、表格行 |
| `border_2` 描边 | `#D3D8DF` | 控件描边 |
| `text_dim` 次级 | `#3C4654` | 说明、描述 |
| `text_mute` 弱化 | `#8A94A2` | 元信息、来源、页脚 |
| `ok` / `bad` | `#2E7D5B` / `#B3261E` | 状态，仅真实链路 |

规则：

1. **朱砂只给三样东西**——引用编号、命中、主操作。一屏之内朱砂超过 5 处，
   说明层级乱了，先砍强调再改文案。
2. **颜色带语义，不带装饰**。界面上出现没定义过的颜色，就是设计出错。
3. **不用纯黑 `#000`**，不用纯白 `#FFF` 做页面底（屏幕上刺眼）。
4. 标志里的朱砂框和界面里的引用编号是同一个角色：它们都表示「被框出来的那一条」。

## 字体与字阶

衬线做标题、答案和数值；无衬线做正文与元信息。字号只有这几档，没有中间值。

| token | 值 | 角色 |
|---|---|---|
| `fs-display` | 21px | 统计数值 |
| `fs-title` | 19px | 提问、顶栏标题 |
| `fs-lead` | 17px | 答案 |
| `fs-body` | 14.5px | 正文、证据条目、轨迹行 |
| `fs-no` | 13px | 引用编号 |
| `fs-sm` | 12px | 次要元信息、来源 |
| `fs-label` | 11px | 小标题、字段标签 |
| `fs-brand` | 16px | 侧边栏字标 |

行高 `1.6`（提问）/ `1.75`（正文）/ `1.85`（答案）；字间距 `0.16em`（小标题）、
`0.04em`（按钮）、`-0.005em`（大标题）。

- 数字用衬线，读数要像读数，不像代码。
- **证据 ID 不用等宽字体**。等宽是控制台的做法，编号用朱砂上标就够了。
- 中文正文与英文来源字号相同（14.5px），不要为了「英文看起来小」再降一档。
- 字体栈：`Songti SC / Georgia / serif`（衬线）、`Inter / PingFang SC`（无衬线）。

4px 基数。

|---|---|---|---|---|

| `space-s2` | 4px | | `radius-md` | 4px（容器） |

| `space-s4` | 12px | | `line-hair` | 1px（分区、表格行） |
| `space-s5` | 16px | | `line-strong` | 2px（顶栏底线、证据首条） |
| `space-s6` | 24px | | | |

圆角超过 4px 的东西不属于这套语言——除了药丸（对照组的切换）。

## 版面

| token | 值 | 含义 |
|---|---|---|
| `layout-max-w` | 1400px | 内容最大宽 |
| `layout-w-key` | 96px | 轨迹行的阶段列宽 |
| `layout-w-no` | 38px | 证据编号列宽 |
| `layout-logo-h` | 40px | 顶栏标志高度 |

两栏：左边影像常驻，右边叙事流。窄屏（≤1250px）全部堆叠成单列，顺序不变。
分区靠分割线，不堆卡片。

## 标志使用

标志是**窗位**：像素值直方图 + 朱砂窗位框。

| 场景 | 规则 |
|---|---|
| 留白 | 四周至少留 1/2 个窗位框宽的空白，四周等距 |
| 最小尺寸 | 印刷 ≥ 8mm，屏幕 ≥ 16px |
| 反白 | 深底上把墨色部分换成纸白，朱砂框保持朱砂 |
| 单色 | 纯黑单色版可用（直方图转黑，朱砂框也转黑） |
| 横版 | 标志 + Georgia Bold 字标，间距取窗位框宽的 1/2 |

**禁止**：不拉伸、不旋转、不加阴影、不加渐变、不换色、不套圆角容器、不加背景色块。
标志是印在纸上的，不是贴在界面上的贴纸。

资产：

| 用途 | 文件 |
|---|---|
| 横版矢量 | `assets/logo/final/radtracerag-lockup.svg` |
| 横版位图 2400px | `assets/logo/final/radtracerag-lockup-2400-{paper,white}.jpg` |
| 标志图标 | `assets/png/logo-mark-{32…1024}.png`、`logo-mark-favicon-{16,32,180}.png` |
| 深浅横版 | `assets/png/logo-lockup.png`、`logo-lockup-light.png` |

## 图形语言

图表、图标、示意图都跟标志同一套构造。

- **直方图**：细长条、等宽、底部对齐，视觉宽度约 9px，间距约为宽度的 0.45 倍
- **描边**：2–3px，端点方头，不用圆头
- **选区**：朱砂描边矩形，不填充——和标志里的窗位框一致
- **分组**：靠 1px 分割线，不靠卡片阴影
- **图标**：线性、单色、24px 网格、2px 描边，不混用多色
- **影像**：不加彩色边框、不做美化滤镜、保留原始灰阶；影像圆角 2px，不圆角以外地处理

## 文案语气

报告语体：陈述，不推销，不兜售。

| 场景 | 写法 |
|---|---|
| 陈述 | 「腹部轴位断层，可见右上腹大片实质脏器影。」——说看到了什么 |
| 不确定 | 「不能仅凭单张图定性。」——不确定就说不确定，不写模糊的肯定句 |
| 没有证据 | 「没有检索到证据，答案没有可回溯的支撑。」——空结果也要占位，不留白 |
| 禁止 | 不用「智能」「高效」「一键」「赋能」；不用感叹号；不写「本系统」 |

## 动效

有，但只做三件事：控件 0.15s 的颜色/透明度过渡、hover 时描边变墨色、
药丸选中态换底色。

不做：入场动画、视差、弹跳、位移。纸面上的东西不会自己动。

## 代码约束

1. **token 单一来源**：`theme.py` 里的 `COLORS / SPACING / TYPE / RADIUS / LINE /
   LEADING / TRACKING / LAYOUT` 是唯一出处。
2. **CSS 里不写字面量**：所有间距、字号、圆角、线宽必须引用 `var(--rt-*)`。
   `theme.py` 的 CSS 主体里应当搜不到 px 字面量（`:root` 里的 token 定义除外）。
3. **颜色语义对应**：新加颜色先问「它在报告里对应哪一句」，答不上来就不加。
4. **机器可读副本**：`assets/style/design-tokens.json` 由
   `assets/make_style_board.py` 从 `theme.py` 导出，供 Figma / 其他端复用。

## 改基调的流程

1. 改 `theme.py` 的 token 字典
2. 跑 `python assets/make_style_board.py`（token JSON + 视觉板一起更新）
3. 起 UI 截图对照，确认视觉漂移在预期内
4. 改 `doc/visual-language.md` 里对应的表格
5. 提交时说明「改的是哪一档、为什么」

不要只改文档不改代码，也不要只改代码不写文档——这两件事必须同时发生，
否则下一个页面会长得不一样。
